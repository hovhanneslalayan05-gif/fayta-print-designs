# FAYTA Print Designs

Druckdateien für FAYTA-Länder × Kampfsport-T-Shirts.

## Armenia / V4 FullCanvas

- 9 Sportarten: MMA, JIU-JITSU, WRESTLING, BOXING, KICKBOXING, MUAY THAI, JUDO, TAEKWONDO, KARATE.
- 18 PNGs: jeweils Black-Shirt (weiße Schrift) und White-Shirt (schwarze Schrift).
- PNG transparent, 4677 × 5881 px, 400 DPI, FullCanvas + MarketPrint Auto-Fit (kein `placement`).
- Beim Hochladen alle 18 Dateien in den Ordner `armenia/` legen; keine V3-Dateien hochladen.

Die FullCanvas-Testprodukte sind nur optisch geprüft. Vor regulärem Verkauf Druckfarben und tatsächlichen Probedruck überprüfen.
